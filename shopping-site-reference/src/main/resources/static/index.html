購物網站 FIDO 串接參考範例（非正式產品）

這不是真正的購物網站，只是示範購物網站後端要怎麼呼叫 fido-server 的 REST API 完成 FIDO 加掛登入的串接（docs/api-contract.md）。畫面陽春、沒有商品/購物車/金流， 重點是能讓人手動點過一次完整流程、看得懂串接邏輯在哪裡。

重要（WebAuthn 瀏覽器限制）：本頁呼叫的種子租戶 rp_id = shop.example.com， 瀏覽器要求 navigator.credentials.create()/get() 的呼叫頁面 origin 的網域必須等於 （或是其可註冊子網域）這個 rp.id。也就是說，若不是真的把本頁部署在 https://shop.example.com（或其子網域）底下開啟，瀏覽器會直接拒絕整個 ceremony （SecurityError），與後端程式碼是否正確無關。本機測試需要先把 shop.example.com 導向本機（hosts 檔）並用受信任的本機憑證（例如 mkcert）以 HTTPS 開啟本頁，詳見專案交付說明。
